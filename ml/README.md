# Machine Learning Module (`ml/`)

This directory is reserved for future stage deliverables in accordance with the ADDMAI Project Constitution (Sections 10, 23, and 24).

## Planned Scope (Stages 3 & 4)
- **Face Processing:** Landmark detection, bounding box isolation, normalization.
- **Deepfake Classifier:** Transfer learning backbones (EfficientNet, ResNet, Xception).
- **Inference Pipeline:** Probabilistic prediction outputting `REAL` or `DEEPFAKE`.
- **Explainability:** Grad-CAM attention heatmap generation.

*Notice: Stage 1 is restricted to development infrastructure. No model training, weights, or ML implementations are present.*
