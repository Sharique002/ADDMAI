# Forensic Engine Module (`forensic/`)

This directory is reserved for future stage deliverables in accordance with the ADDMAI Project Constitution (Section 12).

## Planned Scope (Stage 5)
- **Error Level Analysis (ELA):** Compression discrepancy mapping across image planes.
- **Frequency Domain Analysis:** Discrete Fourier Transform (DFT) artifact inspection.
- **Compression & Quantization:** JPEG double-compression blocking artifact detection.
- **Boundary Anomaly Analysis:** Facial boundary gradient and blending checks.

*Notice: Forensic signals do not declare `REAL` or `FAKE`. They generate quantitative signal evidence for downstream fusion.*
