# Asynchronous Task Worker (`worker/`)

This directory is reserved for future stage deliverables in accordance with the ADDMAI Project Constitution (Section 18).

## Planned Scope (Stage 8)
- **Background Worker Engine:** Redis task consumption.
- **Job Lifecycle Management:** Execution of `QUEUED` -> `PROCESSING` -> `COMPLETED`/`FAILED` state transitions.
- **Pipeline Orchestration:** Dispatching frames to AI detectors, forensic extractors, and fusion engines.
